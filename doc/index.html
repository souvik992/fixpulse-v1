Getting Started

Overview

FixPulseHQ is a workspace-based issue tracker that combines project management, issue tracking, team administration, and spreadsheet sync in one app. Each organization gets its own isolated data, member list, roles, projects, and workflow.

Main Views

Dashboard, Issue List, Projects, Team, and Company Settings.

Who Uses It

Admins, project managers, developers, testers, and viewers across the same workspace.

Where Data Comes From

Native issue creation, Google Sheet sync, Excel upload, or CSV upload.

Getting Started

Quick Start

  1. Open the app and register a company workspace or log in to an existing one.
  2. The first registered user becomes the admin and can access member management and company settings.
  3. Create one or more projects for the products, modules, or teams you want to track.
  4. Add team members from the Team page and assign them the right roles.
  5. Create issues manually or enable a Google Sheet or file-based sync source.
  6. Track work from the Dashboard and Issue List views.
Getting Started

Typical User Journey

1. Intake Issues arrive from manual entry or a synced source.
2. Triage Admins or managers review title, type, priority, project, and assignment.
3. Execution Developers move issues through statuses and collaborate through comments.
4. Review Teams use the issue list and detail views to verify progress and catch stalled work.
5. Reporting Managers export filtered reports or use dashboard metrics for progress reviews.
Core Workflow

Dashboard

The dashboard is the fastest way to understand issue volume, status distribution, and priority mix. It supports all-project and project-specific views.

  • Project switcher to focus on a single project or the full workspace.
  • Status and priority summaries for quick health checks.
  • Recent issues section for immediate drill-down.
  • Export report flow for sharing filtered snapshots.
  • Sync timestamp widget so teams know when external data was last refreshed.
Core Workflow

Issue Management

The Issue List is the most detailed workspace for browsing and managing issues. Each issue can hold title, description, labels, attachments, reference links, comments, and activity history.

Create

Use the create issue modal to set title, project, type, priority, assignee, labels, and references.

Filter

Filter by status, priority, type, assignee, and search text to narrow down work quickly.

Update

Open any issue to change status, priority, assignee, or add discussion and context.

Core Workflow

Projects

Projects help you segment work by product, business area, or implementation stream. Every issue belongs to a project.

Recommended: create a separate project for each major product or source sheet tab so permissions, reporting, and assignment stay clear.

Admin Panel

Roles And Permissions

FixPulseHQ uses role-based access control. Roles may be global or project-scoped, allowing admins to keep permissions precise without over-granting access.

Role Best For Typical Access
Admin Workspace owners Full control over users, projects, roles, settings, and issues.
Project Manager Delivery leads Manage project work, assignments, and issue progress.
Developer Individual contributors Work on assigned issues and update execution state.
Tester QA teams Create bugs, verify fixes, and collaborate in comments.
Viewer Stakeholders Read-only visibility into issues and reports.
Admin tip: prefer project-scoped roles whenever a user only needs access to one product area.
Admin Panel

Company Settings

Company Settings is the administrative control center for the workspace. Admins can update organisation profile details and configure external issue sources.

  • Update organization name, branding color, and logo.
  • Configure a data source type such as Google Sheet, Excel, or CSV.
  • Enable or pause automatic sync for the workspace.
  • Review last sync timestamp and latest sync errors.
  • Store an Apps Script URL for direct write-back to Google Sheets.
Admin Checklist
1. Open Settings
2. Choose a data source type
3. Paste the Google Sheet link or upload a file
4. Turn on sync
5. Save settings
6. Run "Sync Now" to verify incoming issues
Admin Panel

Sheet Sync And Write-back

Sync is designed for teams that already track work in spreadsheets and want FixPulseHQ to become the operational interface without losing that source of truth.

Import Behavior

Each tab becomes a project. Matching issue rows are imported and enriched with metadata like source tab and source row.

Manual Sync

Use the sync action when you need a fresh pull immediately instead of waiting for scheduled sync.

Write-back

Add an Apps Script Web App URL to push issues back into Google Sheets from the app.

Important: keep source sheet headers consistent. Clean header naming leads to better mapping for reporter, status, priority, and assignee fields.
Support

Best Practices

  • Use short, specific issue titles that describe the user-visible problem.
  • Assign every active issue to one owner whenever possible.
  • Keep project boundaries clean so reporting and permissions stay reliable.
  • Use comments for decisions, blockers, and test notes instead of leaving context offline.
  • Review sync settings after changing sheet structure or importing new workbooks.
Support

FAQ

Why can some users not assign issues?

Assignment requires the appropriate project permission, usually provided through an admin or manager role.

Why does the app show “All Projects” in some places?

This means the page is currently displaying workspace-wide data rather than a single project filter.

Can I use spreadsheets and manual issue creation together?

Yes. FixPulseHQ supports native issue creation even when a workspace also syncs from Google Sheets or uploaded files.

Where should admins troubleshoot sync problems?

Start in Company Settings, review last sync status, then verify the source link, file structure, and Apps Script URL if write-back is enabled.

Troubleshooting

Problem Likely Cause What To Check
User cannot see a page Role or permission gap Review the user’s assigned roles and project scope.
Issues are missing after import Source row mapping or weak sheet headers Check the sheet structure, source tab content, and sync status.
Assignment looks empty Assignee could not be matched from source data Verify source sheet headers and member records.
Write-back does not work Apps Script URL is missing or misconfigured Re-deploy the script as a web app and re-save the URL.
