# FixPulseHQ Docs

This folder is intentionally standalone and not integrated into the main app.

Files:

- `index.html`
- `login.html`
- `manage.html`
- `styles.css`
- `app.js`
- `docs-auth.js`
- `logo.svg`

How to use:

1. Open `doc/index.html` directly in a browser, or
2. Serve the `doc` folder with any static file server.

Example:

```bash
npx serve doc
```

Then open the URL shown by the server.

Docs admin:

- Login page: `doc/admin/`
- Manage page: `doc/manage.html`
- Default local credentials: `docsadmin` / `fixpulse-docs`
